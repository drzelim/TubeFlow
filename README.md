# TubeFlow

<img src="icons/icon-128.png" alt="TubeFlow" width="64" height="64">

Небольшое расширение для Chrome, которое скрывает YouTube Shorts и управляет скоростью видео.

## Возможности

- Включение и отключение скрытия Shorts.
- Скорость воспроизведения от 0,25× до 4× с шагом 0,25×.
- Окно настроек по нажатию на значок расширения.
- Локальное сохранение настроек и применение в открытых вкладках YouTube.

По умолчанию Shorts скрыты, скорость воспроизведения — 2×.

## Установка

1. Скачайте репозиторий и распакуйте архив или клонируйте его через Git.
2. Откройте `chrome://extensions` и включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку с `manifest.json`.
4. Откройте или перезагрузите страницу YouTube.

## Использование

Нажмите на значок **TubeFlow** в меню расширений. Переключатель управляет скрытием Shorts, ползунок и кнопки **−** / **+** — скоростью видео. Изменения сохраняются автоматически.

На странице YouTube работают стандартные сочетания: **Shift + .** (`>`) увеличивает скорость, **Shift + ,** (`<`) уменьшает её. Шаг — 0,25×, диапазон — 0,25–4×. При вводе текста сочетания не перехватываются.

При смене скорости с клавиатуры текущее значение появляется поверх видео на две секунды. Повторное нажатие обновляет индикатор и продлевает его показ.

После обновления файлов нажмите кнопку обновления расширения на `chrome://extensions` и перезагрузите вкладки YouTube.

## Разработка

JavaScript и Manifest V3, без сборки и сторонних зависимостей. Для запуска тестов нужен Node.js:

```sh
node --test
```
